One funny single-line one-star review from a house cat about its human, written for make.fun's "Make the AI Judge Laugh: Cat Reviews Its Human" bounty.

> One star. He shuts the bathroom door like he owns the place. I yowl until he opens it, then leave. I never wanted in. I wanted him to know I could.

## Run it

```sh
python3 main.py
```

The program writes the review to `/output/entry.txt` and prints exactly the line, nothing else.
